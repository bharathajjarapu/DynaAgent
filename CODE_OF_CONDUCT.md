# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Standards

- Be respectful, inclusive and constructive; critique ideas, not people.
- Credit prior work and co-authors; report results honestly and reproducibly.
- No harassment, discrimination, personal attacks or publishing others' private information.

## Scope

All project spaces: issues, pull requests, discussions and project communications.

## Enforcement

Report incidents privately to the maintainers via [GitHub](https://github.com/bharathajjarapu). Reports are reviewed promptly and kept confidential. Maintainers may edit or remove contributions and warn, suspend or ban participants who violate this code.
